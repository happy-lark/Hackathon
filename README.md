# PersonaLAB
- Image analysis and editing application service 
- 3rd Place at USC Conference Hackathon (July 2026) 

## ⭐Summary
- PersonaLAB is an AI-powered image optimization service that anaylzes user photos based on a target persona and provides feedback
- Offers personalized image editing capablities 

## 🛠️Tech Stack 
- Language: Python
- Frontend & UI: Streamlit, HTML/CSS
- Computer Vision & Image Processing: MediaPipe, OpenCV, Pillow 

## ✅Key Features
1. Target Persona & Context Selection
   - Select a target persona and purpose (e.g., Professional Profile, Portfolio/Website, Networking/Conference, Creator/Personal Brand).

2. Photo Upload & Match Analysis
   - Upload up to 5 photos at once.
   - Evaluates each photo's compatibility with the selected persona and selects the best fit.

3. Image Match Report
   - Detailed analysis including: Match Score, Strengths, Areas for Improvement, and Personal Color Recommendation.

4. Persona-based Image Editing
   - Background Customization: Change background to recommended personal color, office/urban/nature settings, or apply a blur effect.
   - Fine Tuning: Adjust brightness, contrast, saturation, and sharpness.

5. Optimized Export
- Download the optimized image in 2 formats*: Original aspect ratio or Circular crop profile.
